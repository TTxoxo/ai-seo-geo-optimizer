AI SEO GEO Optimizer is a WordPress plugin that prepares a review-first workflow for AI-generated SEO/GEO optimization suggestions.

== Description ==

This release provides the plugin foundation:
- Plugin activation and installer
- Database table creation
- Admin menu and starter admin pages
- Security helper and log manager foundation

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate the plugin through the WordPress Plugins screen.
3. Open **AI SEO Optimizer** from the WordPress admin menu.
